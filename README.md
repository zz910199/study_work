# July的知识库

一个供个人学习、记录和整理使用的本地知识库（study_work）。包含文章、笔记和代码片段，无需域名、远程服务器、账号或安装依赖。

## 启动

- Windows：双击 `start.bat`。
- 其他系统：直接用浏览器打开 `index.html`。

网站使用本地 HTML、CSS 和 JavaScript，打开后不需要联网。它不是已经部署的 GitHub Pages 网站；这个仓库目前用于保存网站源文件。

## 功能

- 首页展示最近更新和文章、笔记、代码三个分类入口。
- 浏览分类并搜索标题、简介、标签和正文。
- 在网页中新建、编辑和删除内容。
- 切换浅色、深色或跟随系统的主题。
- 上传头像，替换默认的字母头像。
- 首次打开时显示一篇介绍文章、三条笔记和两个代码片段。

## 数据保存与备份

**网页里编辑的内容及上传的头像保存在当前浏览器的 `localStorage`，不是仓库里的文件。** `git push`、复制这个项目文件夹或在另一台电脑克隆仓库，都不会同步这些浏览器数据。清除网站数据、更换浏览器或浏览器配置文件，可能使编辑内容丢失。

当前版本没有导出/导入功能。重要内容请另外保存原文，勿将浏览器存储作为唯一备份。首次显示的示例内容写在 `app.js` 中；一旦当前浏览器保存过内容，后续修改示例内容不会覆盖已保存的数据。

## 文件结构

```text
.
├── index.html   # 页面入口
├── styles.css   # 页面样式和主题
├── app.js       # 页面交互和初始示例内容
├── start.bat    # Windows 启动脚本
└── README.md    # 使用说明
```

网站仅供本地使用，但仓库的可见性由 GitHub 仓库设置决定。不要把私人笔记、密码或其他敏感信息写进 `app.js` 后提交到公开仓库。
